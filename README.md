# skemo

**Draw diagrams as text, get a polished image.** skemo turns a readable text file (`.skemo`) into an
architecture, network or process diagram, a timeline, a frieze or a mind map, rendered as **PNG, SVG, WebP,
HTML animated step by step, GIF or animated PNG**. The layout and the arrows are automatic; the look is CSS.

> **This code is 100 % generated by AI** (Claude, Anthropic), under human direction but without line-by-line
> human review. It is provided "as is", without warranty of any kind (see the licenses); the author accepts no

| The text | The result |
|---|---|
| <pre>diagram(dir="down")<br><br>  card#internet.cloud Internet<br>    to(fw) WAN<br><br>  card#fw.firewall Firewall<br>    li 203.0.113.10/29<br>    to(web)<br>    to(base)<br><br>  zone#internal.internal Internal network<br>    card#web.server Web server<br>      li 10.0.0.10<br>      to(base)<br>    card#base.server Database<br>      li 10.0.0.20</pre> | <img src="cli/docs/example.png" width="280" alt="Diagram produced by skemo"> |

- **Text is the source**: a diagram is read, diffed and reviewed like code.
- **Automatic layout, hand-tuned where you want**: cards place themselves; pin what you care about (`at=`),
  force a side or a waypoint on an arrow (`side=`, `via=`).
- **Styling is CSS**: light, dark and print themes, with a built-in contrast check.
- **Step-by-step animation** for presentations (`@1`, `@2:up`, `@3-5:focus`).
- **One binary, no dependencies**: no Node, no browser, no Graphviz; fonts and theme are embedded, and the output
  is identical from one machine to the next. The same engine runs in the browser as WebAssembly.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/skemonet/skemo/main/cli/install.sh | sh            # latest release into ~/.local/bin, SHA-256 checked
```

Or take a binary from the [releases](https://github.com/skemonet/skemo/releases) (Linux x86_64 and ARM, macOS ARM, Windows), or build it
(Rust 1.85 or later, [rustup.rs](https://rustup.rs)):

```bash
git clone https://github.com/skemonet/skemo skemo && cd skemo
cargo build --release -p skemo-cli       # the binary: target/release/skemo
```

## Getting started

```bash
skemo init my-diagram                    # example.skemo and a commented custom.css
cd my-diagram
skemo example.skemo --css custom.css     # writes example.png
skemo watch example.skemo --css custom.css   # live preview in the browser
```

The format is described in [`lang/FORMAT.md`](lang/FORMAT.md) and in the user documentation,
[docs.skemo.net](https://docs.skemo.net) (built from [`lang/site/`](lang/site)). The commands are listed in
[`cli/README.md`](cli/README.md). AI agents can use the [skemo skill](cli/skill/skemo/SKILL.md).

## Repository layout

Five Rust crates in one Cargo workspace:

| Folder | Crate | Role |
|---|---|---|
| [`router/`](router) | `skemo-router` | generic orthogonal connector router, usable on its own (no dependency) |
| [`lang/`](lang) | `skemo-lang` | the language: format, parser, model, diagnostics, CSS styles, surgical editing |
| [`engine/`](engine) | `skemo-engine`, `skemo-engine-wasm` | measurement, layout (ELK), routing, rendering, animation; WebAssembly API |
| [`cli/`](cli) | `skemo-cli` | the `skemo` command-line tool and the agent skill |

`lang` and `router` depend on nothing in the project; `engine` uses both; `cli` is a thin layer over `engine` and
`lang`. Each folder has a `README.md` (usage) and a `SPEC.md` (requirements).
