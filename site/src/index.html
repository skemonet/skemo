How it reads

Plain text in, a polished diagram out.

A .skemo file is plain text: cards, zones that group them, and arrows written inside the card they leave. No coordinates unless you want them. The look is CSS: one card type is one line.

Why skemo

A diagram you can keep, review and rerun.

{{icon:git-compare}} The same diagram every run

Fonts and theme are built in: one file gives the same pixels on every machine. Commit the source, review it in a pull request, render it in CI.

{{icon:layout-dashboard}} Automatic, stable layout

Cards place themselves and arrows route around obstacles. Editing one card only moves its own arrows; pin what you care about with at="x,y".

{{icon:palette}} Styled with CSS

A type is a class: .server { --c: #5B6CFF; }. Tints, borders and inks derive from one accent, so light, dark and print themes come for free.

{{icon:package}} One binary, offline

No Node, no browser, no Graphviz, no network. The diagram of a private system never leaves your machine. Also available as WebAssembly.

{{icon:presentation}} Animated when you need it

Add @1, @2:up to unfold a diagram in a talk, or .pulse to show traffic, as HTML, GIF, animated PNG or WebP.

{{icon:contrast}} Readable by design

A built-in contrast check, a print theme that survives black and white, and types that never rely on colour alone.

Fewer tokens, less CO₂

Every token not generated is energy not spent.

Generating text is the expensive part of using a language model: each output token is a full pass through the model on a data-centre GPU. When the model draws the picture itself, most of those tokens are coordinates. skemo moves that work to a deterministic program that runs on your CPU in a few milliseconds.

How these numbers are measured

For each gallery example we count the tokens of the .skemo source plus its CSS, and the tokens of the SVG that skemo renders from it — the same picture with every coordinate written out, which is what a model has to produce when it draws directly. That SVG is first reduced to what a careful hand would write: no embedded source, no class or data attributes, the font declared once, coordinates to one decimal. Both sides are counted with the same byte-pair-like approximation (words, groups of up to three digits, punctuation); real tokenizers give different absolute counts, but the ratio between the two routes is what matters. The script is site/tools/measure_tokens.py, and the build of this page reruns it: the figures are never typed by hand. They count the diagram's text only: on a whole task, where reading the input, the skill and the rendered images dominates, the saving is smaller ({{task:saving_percent}} % on our first measured task, see the questions below).

For AI agents

Teach your agent skemo in one file.

The skemo skill tells a coding agent (Claude Code, or any agent that reads SKILL.md skills) how to write a diagram, check it and render it, with the rules that keep files short. More on agents.

  1. Install the skemo binary (below) so the agent can run it.
  2. Copy the skill into your skills folder: 
    mkdir -p ~/.claude/skills/skemo/references
curl -fsSL https://skemo.net/skill/skemo/SKILL.md -o ~/.claude/skills/skemo/SKILL.md
curl -fsSL https://skemo.net/skill/skemo/references/format.md -o ~/.claude/skills/skemo/references/format.md
  3. Ask for a diagram: “draw our deployment as a skemo diagram”. The agent writes the .skemo file, runs skemo lint, then renders it.

Questions

Good to know

How is it different from Mermaid or D2?

All three are text. skemo is built for diagrams people show: the look is plain CSS, layout is stable when you edit (only the arrows of what changed move), positions can be pinned by hand or from the editor and written back into the text, rendering needs no browser, and the same file can unfold step by step. Mermaid has more diagram kinds (sequence diagrams, class diagrams, charts); skemo does not draw those today.

Does the agent need to see the image?

It looks, as a person would: in our test on a Terraform platform the agent read every image it rendered. What changes is what it fixes there. skemo lint catches structural mistakes as text and the layout is automatic, so the agent reads the picture to judge it, not to move boxes by hand.

Is it free?

Yes. skemo is open source, licensed MIT OR Apache-2.0, and in pre-release ({{version}}): the format may still change before 1.0. The embedded fonts are under the SIL Open Font License, the icons under ISC.

What do the token figures measure?

The figures above compare the text of a diagram: a .skemo source against the SVG of the same picture. A whole task costs more than its output: reading the input, the skill and the rendered images.
