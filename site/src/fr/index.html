Comment ça se lit

Du texte simple en entrée, un diagramme soigné en sortie.

Un fichier .skemo, c’est du texte : des cartes, des zones qui les regroupent, et des flèches écrites dans la carte qu’elles quittent. Pas de coordonnées, sauf si vous en voulez. L’apparence, c’est du CSS : un type de carte tient en une ligne.

Pourquoi skemo

Un diagramme que l’on garde, relit et refait.

{{icon:git-compare}} Le même diagramme à chaque fois

Polices et thème sont intégrés : un fichier donne les mêmes pixels sur toutes les machines. Versionnez la source, relisez-la en pull request, rendez-la en CI.

{{icon:layout-dashboard}} Un placement automatique et stable

Les cartes se placent seules et les flèches contournent les obstacles. Modifier une carte ne déplace que ses flèches ; épinglez ce qui compte avec at="x,y".

{{icon:palette}} Stylé en CSS

Un type est une classe : .server { --c: #5B6CFF; }. Teintes, bordures et encres découlent d’un accent : les thèmes clair, sombre et impression viennent tout seuls.

{{icon:package}} Un exécutable, hors ligne

Ni Node, ni navigateur, ni Graphviz, ni réseau. Le schéma d’un système privé ne quitte jamais votre machine. Existe aussi en WebAssembly.

{{icon:presentation}} Animé quand il le faut

Ajoutez @1, @2:up pour dérouler un diagramme pendant un exposé, ou .pulse pour montrer le trafic, en HTML, GIF, PNG ou WebP animé.

{{icon:contrast}} Lisible par construction

Un contrôle de contraste intégré, un thème impression qui tient en noir et blanc, et des types qui ne reposent jamais sur la couleur seule.

Moins de tokens, moins de CO₂

Chaque token non généré est de l’énergie non dépensée.

Générer du texte est la partie coûteuse d’un modèle de langage : chaque token produit est un passage complet du modèle sur un GPU de centre de données. Quand le modèle dessine l’image lui-même, la plupart de ces tokens sont des coordonnées. skemo confie ce travail à un programme déterministe qui tourne sur votre processeur en quelques millisecondes.

Comment ces chiffres sont mesurés

Pour chaque exemple de la galerie, nous comptons les tokens de la source .skemo et de son CSS, et les tokens du SVG que skemo en tire : la même image avec chaque coordonnée écrite, ce qu’un modèle doit produire quand il dessine lui-même. Ce SVG est d’abord réduit à ce qu’une main soigneuse écrirait : pas de source intégrée, pas d’attributs de classe ou de données, la police déclarée une fois, des coordonnées à une décimale. Les deux côtés sont comptés avec la même approximation de type byte-pair (mots, groupes de trois chiffres au plus, ponctuation) ; les vrais tokeniseurs donnent d’autres valeurs absolues, mais c’est le rapport entre les deux voies qui compte. Le script est site/tools/measure_tokens.py, et le build de cette page le relance : les chiffres ne sont jamais tapés à la main. Ils ne comptent que le texte du diagramme : sur une tâche complète, où lire l’entrée, la compétence et les images rendues domine, l’économie est plus faible ({{task:saving_percent}} % sur notre première tâche mesurée, voir les questions plus bas).

Pour les agents IA

Apprenez skemo à votre agent en un fichier.

La compétence skemo explique à un agent de code (Claude Code, ou tout agent qui lit les compétences SKILL.md) comment écrire un diagramme, le vérifier et le rendre, avec les règles qui gardent les fichiers courts. En savoir plus.

  1. Installez l’exécutable skemo (ci-dessous) pour que l’agent puisse le lancer.
  2. Copiez la compétence dans votre dossier de compétences : 
    mkdir -p ~/.claude/skills/skemo/references
curl -fsSL https://skemo.net/skill/skemo/SKILL.md -o ~/.claude/skills/skemo/SKILL.md
curl -fsSL https://skemo.net/skill/skemo/references/format.md -o ~/.claude/skills/skemo/references/format.md
  3. Demandez un diagramme : « dessine notre déploiement en diagramme skemo ». L’agent écrit le fichier .skemo, lance skemo check, puis le rend.
Installation

Prêt en une minute.

Linux et macOS

curl -fsSL https://raw.githubusercontent.com/skemonet/skemo/main/cli/install.sh | sh

S’installe dans ~/.local/bin après vérification du SHA-256. Windows : prenez le .exe sur la page des versions.

Premier diagramme

skemo init mon-diagramme
cd mon-diagramme
skemo example.skemo --css custom.css    # → example.png
skemo watch example.skemo               # aperçu en direct

Ensuite : premiers pas.

Questions

Bon à savoir

Quelle différence avec Mermaid ou D2 ?

Les trois sont du texte. skemo est fait pour les diagrammes que l’on montre : l’apparence est du CSS, le placement reste stable quand on modifie (seules les flèches de ce qui a changé bougent), les positions s’épinglent à la main ou depuis l’éditeur et sont réécrites dans le texte, le rendu n’a pas besoin de navigateur, et le même fichier peut se dérouler pas à pas. Mermaid couvre plus de types (diagrammes de séquence, de classes, graphiques) ; skemo ne les dessine pas aujourd’hui.

L’agent a-t-il besoin de voir l’image ?

Il la regarde, comme une personne : dans notre test sur une plateforme Terraform, l’agent a lu chaque image qu’il a rendue. Ce qui change, c’est ce qu’il y corrige. skemo check repère les erreurs de structure sous forme de texte et le placement est automatique : l’agent lit l’image pour en juger, pas pour déplacer des boîtes à la main.

Est-ce gratuit ?

Oui. skemo est libre, sous licence MIT OU Apache-2.0, et en préversion ({{version}}) : le format peut encore changer avant la 1.0. Les polices intégrées sont sous SIL Open Font License, les icônes sous ISC.

Que mesurent les chiffres de tokens ?

Les chiffres ci-dessus comparent le texte d’un diagramme : une source .skemo contre le SVG de la même image. Une tâche complète coûte plus que sa sortie : lire l’entrée, la compétence et les images rendues. Mesuré sur une tâche complète (un diagramme d’architecture tiré d’un export Terraform, {{task:runs}} essai, même modèle avec et sans la compétence), l’agent avec skemo a dépensé {{task:saving_percent}} % de tokens en moins ({{task:tokens_with}} contre {{task:tokens_without}}) et a été {{task:speedup}} fois plus rapide. D’autres tâches seront mesurées de la même façon.
