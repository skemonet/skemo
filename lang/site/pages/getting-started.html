Getting started

Install the skemo binary, write a file, render it. Two minutes.

Install

On Linux (x86_64, ARM) and macOS (ARM):

curl -fsSL https://raw.githubusercontent.com/skemonet/skemo/main/cli/install.sh | sh

The script downloads the latest release, checks its SHA-256 and installs it into ~/.local/bin (SKEMO_BIN changes the folder, SKEMO_VERSION picks a version). On Windows, take skemo-<version>-x86_64-pc-windows-msvc.exe from the releases page. skemo is a single executable: no Node, no browser, no Graphviz; fonts and theme are built in.

skemo --version

A first diagram

Create hello.skemo:

and render it:

skemo hello.skemo                 # writes hello.png next to the source
skemo hello.skemo -o hello.svg    # the extension picks the format: svg, webp, html, gif, apng

A card is card#id Title. An arrow is written inside the card it leaves: to(b) under card#a draws a → b.

Start from a sample

skemo init my-diagram     # example.skemo and a commented custom.css; overwrites nothing
cd my-diagram
skemo example.skemo --css custom.css
skemo watch example.skemo --css custom.css   # live preview on http://127.0.0.1:8710

watch re-renders on every save and the browser page reloads by itself.

Check before rendering

skemo check example.skemo

Errors come with their line, their column and a hint, for instance unknown target « databse »: did you mean « database »?. The exit code is 1 when there are errors. See Errors and warnings.

Next steps
