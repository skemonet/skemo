Diagrammes en code

Un fichier .skemo, c’est quelques lignes de texte. Il vit dans le dépôt à côté de ce qu’il décrit, change en pull request comme le code, et donne la même image sur toutes les machines.

Pourquoi du texte

  • Relisible. Ajouter un service, c’est une ligne dans le diff, pas une image binaire à comparer à l’œil.
  • Déterministe. Polices et thème sont intégrés à l’exécutable : le même fichier donne les mêmes pixels partout, on peut donc versionner et comparer les images rendues.
  • Stable à l’édition. Une modification ne déplace que les flèches de ce qui a changé ; épinglez une carte avec at="x,y" pour la garder en place.
  • Hors ligne. Un exécutable, pas de navigateur, pas de Node, pas de réseau : le schéma d’un système privé ne quitte jamais votre machine.

Vérifier et rendre en CI

skemo lint docs/*.skemo --deny-warnings          # code de sortie 1 au moindre problème
skemo render docs/architecture.skemo -o docs/architecture.svg --deny-warnings

Une étape GitHub Actions, par exemple :

- run: curl -fsSL https://raw.githubusercontent.com/skemonet/skemo/main/cli/install.sh | sh
- run: ~/.local/bin/skemo lint docs/*.skemo --deny-warnings

Sorties

FormatUsage
PNG, WebPREADME, wikis, messageries, présentations (--scale 2 pour les écrans denses, --transparent)
SVGsites de documentation : net à toute taille, texte sélectionnable et indexé par les moteurs de recherche
HTMLune page autonome avec thèmes clair et sombre, lecteur pas à pas et flèches animées
GIF, APNG, WebP animédes animations là où aucun script ne tourne

Des images qui se rouvrent

Chaque image rendue par skemo porte sa source et ses feuilles de style dans des métadonnées que les visionneuses ignorent. Partagez le PNG seul ; plus tard, skemo extract diagramme.png rend le texte, et toute commande accepte l’image à la place de la source. Rendez avec --no-source quand la source ne doit pas voyager avec l’image.

Aperçu en direct pendant l’écriture

skemo docs/architecture.skemo --watch --css docs/architecture.css   # http://127.0.0.1:8710

La page se recharge à chaque enregistrement. skemo lint --fix garde les fichiers sous une forme canonique : les diffs restent petits.
