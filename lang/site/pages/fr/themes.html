Thèmes et contraste

Chaque diagramme existe en quatre thèmes. Comme les types ne définissent qu’un accent, changer de thème ne demande aucune modification de votre CSS.

Les thèmes

ThèmeUsage
lightpar défaut ; textes secondaires, flèches et bordures gardent un contraste d’au moins 4,5:1
darkécrans sombres : seules les couleurs de base changent, les teintes sont recalculées depuis --c
printpapier, noir et blanc compris : fond blanc, encre noire, pas d’ombre, remplissages plus foncés et traits plus épais. Appliqué automatiquement quand la sortie HTML est imprimée
autoHTML seulement : suit le réglage du système du lecteur. PNG et SVG se rendent en light

Choisissez avec diagram(theme="dark") ou, en passant outre le fichier, skemo render --theme dark.

Sombre

Impression

Le thème impression peut changer légèrement les dimensions (bordures plus épaisses) : le placement est calculé pour le thème demandé.

Contraste

skemo lint --contrast diagramme.skemo           # signale les textes sous le seuil WCAG
skemo render --contrast high diagramme.skemo     # fonce (ou éclaircit) ces textes, placement inchangé

Le seuil est de 4,5:1 pour le texte, 3:1 pour le texte sur un fond d’accent et pour les icônes. Un accent personnalisé trop clair est signalé, avec l’élément et le rapport mesuré.

Jamais la couleur seule

Les lecteurs qui ne voient pas les couleurs, et les imprimantes, doivent aussi distinguer les types : donnez aux types un --label, et aux flèches dont le sens compte un style de trait (.dashed, .dotted, .thick, .link).
