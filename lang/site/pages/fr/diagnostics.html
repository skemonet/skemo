Erreurs et avertissements

skemo lint et chaque rendu signalent les problèmes avec le fichier, la ligne, la colonne, un repère sous le fautif et, souvent, une aide.

erreur[unknown-target] : cible « b » inconnue
  ┌─ diagramme.skemo:2:6
  │
2 │   to(b) va
  │      ^
  = aide : vouliez-vous « a » ?

Les erreurs arrêtent le rendu (code de sortie 1). Les avertissements jamais, sauf avec --deny-warnings. Les codes sont stables : vous pouvez vous y fier dans des scripts. Les messages suivent la langue du système.

CodeCause

focus-outside, highlight-outsideune mise en valeur ou une mise en évidence pendant que l’élément est caché

Avertissements des feuilles de style

Ils pointent la ligne du fichier .css.

CodeCause
css-propertyune faute de frappe sur une propriété que skemo ou CSS connaît : colr, --lable (le message propose le bon nom). Vos propres variables et tout CSS valide sont laissés tranquilles
css-syntaxune { jamais fermée, une } sans {, une déclaration hors d’une règle ou sans :

Avec --contrast, un contraste sous le seuil est signalé aussi.
