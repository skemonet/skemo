Ligne de commande

skemo est un seul exécutable. Le rendu est sa commande par défaut : skemo f.skemo écrit f.png.

Commandes

CommandeRôle
skemo f.skemocomme skemo render f.skemo : écrit f.png à côté de la source
skemo render f.skemo -o sortie.extl’extension choisit le format : png svg webp html gif apng
skemo check f.skemo…diagnostics seulement (code de sortie 1 en cas d’erreur) ; --contrast ajoute le contrôle de lisibilité
skemo fmt f.skemo… [--check]mise en forme canonique
skemo watch f.skemoaperçu en direct sur http://127.0.0.1:8710, rechargé à chaque enregistrement
skemo layout f.skemo --jsonmodèle, positions et tracés en JSON
skemo fit f.skemo [--target 16:9] [--write]réglages (dir, wrap) qui amènent le diagramme à des proportions cibles ; --write applique le meilleur (préversion)
skemo extract image.png [-o dossier]rend la source et les feuilles de style intégrées dans une image produite par skemo, pour les modifier (--stdout : la source seule)
skemo icons [requête]les icônes intégrées, filtrées par nom ou mot-clé
skemo theme --printle thème par défaut, point de départ du vôtre
skemo init [dossier]un diagramme d’exemple et un fichier CSS commenté ; n’écrase rien

Options de rendu

OptionEffet
-o FICHIERfichier de sortie ; - = sortie standard (avec --format)
--format FMThtml svg png gif apng webp, quand l’extension ne suffit pas
--css FICHIERfeuille de style personnelle, après le thème (répétable)
--base-theme FICHIERun thème qui remplace celui par défaut
--theme Tlight dark print auto, en passant outre le fichier
--scale Nrésolution des sorties matricielles (--scale 2 pour les écrans denses)
--transparentpas de fond (SVG, PNG, APNG)
--contrast highles textes sous le seuil WCAG sont foncés ou éclaircis, placement inchangé
--step Nrendre un état de l’animation
--animated, --boardun PNG par état, ou une planche de tous les états
--hold, --transition, --fps, --final-hold, --no-loop minutage du GIF et de l’APNG
--motionSVG : jouer les flèches .pulse et .flow (Flux animés)
--no-fontsHTML : ne pas intégrer les polices (fichier bien plus petit)
--embed-fontsSVG : intégrer les polices utilisées, pour les visionneuses sans Inter (environ 0,8 Mo par graisse)
--font-scale Kmultiplie toutes les tailles de texte du thème (1.4 pour une diapositive)
--no-sourcene pas intégrer la source et les feuilles de style dans la sortie (ci-dessous)
--deny-warningséchouer au moindre avertissement (utile en CI)

L’entrée - lit l’entrée standard : cat f.skemo | skemo render - --format svg -o - > f.svg.

Des images qui se rouvrent

Comme draw.io, chaque fichier rendu par skemo porte sa source et ses feuilles de style (PNG, APNG, SVG, WebP, GIF et HTML), dans des métadonnées que les visionneuses ignorent. L’image peut se partager seule et se modifier plus tard :

skemo extract diagramme.png              # écrit diagramme.skemo et ses feuilles de style à côté de l’image
skemo render diagramme.png -o nouveau.svg # toute commande accepte aussi l’image à la place de la source

L’éditeur ouvre directement une telle image. Le texte intégré est lisible par quiconque reçoit le fichier : rendez avec --no-source quand la source ne doit pas voyager avec l’image.

0succès
1erreurs dans le fichier

3erreur interne

Langue

L’aide, les diagnostics et les messages suivent la langue du système (LANG, LC_ALL… comme d’habitude ; anglais et français aujourd’hui). --lang en|fr ou SKEMO_LANG=fr la remplace. Les libellés dessinés par le moteur (mois, siècles) la suivent aussi, sauf si le diagramme les fixe avec diagram(lang="fr").

Déterminisme

Polices et thème sont intégrés : le même fichier donne la même image sur toutes les machines, ce qui permet de versionner et de comparer les fichiers rendus. watch n’écoute que sur 127.0.0.1.
