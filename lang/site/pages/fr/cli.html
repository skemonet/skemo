Ligne de commande

skemo est un seul exécutable. Le rendu est sa commande par défaut : skemo f.skemo écrit f.png.

Commandes

CommandeRôle
skemo init [fichier] [--css [nom]]un diagramme d’exemple (diagram.skemo) ; avec --css, une feuille de style commentée qu’il inclut (skemo_style.css) ; n’écrase rien
skemo f.skemocomme skemo render f.skemo : écrit f.png à côté de la source
skemo render f.skemo -o sortie.extl’extension choisit le format : png svg webp html gif apng
skemo lint f.skemo…diagnostics seulement (code de sortie 1 en cas d’erreur) ; --contrast ajoute le contrôle de lisibilité
skemo lint --fix f.skemo… [--dry]mise en forme canonique
skemo f.skemo --watchaperçu en direct sur http://127.0.0.1:8710, rechargé à chaque enregistrement
skemo layout f.skemo --jsonmodèle, positions et tracés en JSON
skemo lint f.skemo --fit [16:9] [--fix]réglages (dir, wrap) qui amènent le diagramme à des proportions cibles ; --fix applique le meilleur (préversion)
skemo site dossier -o sortieun site web à partir d’un dossier de schémas : une carte liée à un autre .skemo (href="shop/api.skemo") ouvre sa page au clic ; fil d’Ariane, liste des schémas, déplacement et zoom (préversion, voir plus bas)
skemo extract image.png [-o dossier]rend la source et les feuilles de style intégrées dans une image produite par skemo, pour les modifier (--stdout : la source seule) ; deux feuilles de même nom reviennent en skemo.css et skemo-2.css
skemo icons [requête]les icônes intégrées, filtrées par nom ou mot-clé ; --json pour les éditeurs et la complétion (absente de --help)

Options de rendu

OptionEffet
-o FICHIERfichier de sortie ; - = sortie standard (avec --format)
--format FMThtml svg png gif apng webp, quand l’extension ne suffit pas
--css FICHIERfeuille de style personnelle, après le thème (répétable)
--base-theme FICHIERun thème qui remplace celui par défaut
--theme Tlight dark print auto, en passant outre le fichier (auto suit le lecteur en HTML seulement ; les autres formats sont dessinés en clair, avec un avertissement)
--scale Nrésolution des sorties matricielles (--scale 2 pour les écrans denses)
--transparentpas de fond (SVG, PNG, APNG)
--contrast highles textes sous le seuil WCAG sont foncés ou éclaircis, placement inchangé
--step Nrendre un état de l’animation
--animated, --boardun PNG par état, ou une planche de tous les états
--hold, --transition, --fps, --final-hold, --no-loop minutage du GIF et de l’APNG
--motionSVG : jouer les flèches .pulse et .flow (Flux animés)
--no-fontsHTML : ne pas intégrer les polices (fichier bien plus petit)
--embed-fontsSVG : intégrer les polices utilisées, pour les visionneuses sans Inter (environ 0,8 Mo par graisse)
--font-scale Kmultiplie toutes les tailles de texte du thème (1.4 pour une diapositive)
--no-sourcene pas intégrer la source et les feuilles de style dans la sortie (ci-dessous)
--deny-warningséchouer au moindre avertissement (utile en CI)
--allow CODEécarter les avertissements de ce code : ni affichés, ni comptés par --deny-warnings (--allow step-gap,overlap)

L’entrée - lit l’entrée standard : cat f.skemo | skemo render - --format svg -o - > f.svg.

Lancer skemo depuis un outil

Pour un programme qui lance skemo (un outil de présentation, une CI, un éditeur), la ligne de commande est un contrat stable (cli/SPEC.md §2) :

OptionEffet
codes de sortie0 rendu, 1 schéma refusé (rien sur la sortie standard), 2 mauvaise utilisation, 3 erreur interne
--diagnostics jsonun objet JSON par ligne sur la sortie d’erreur : gravité, code stable, message, fichier, ligne et colonne
--root DOSSIERles images et feuilles de style que nomme le schéma ne sont lues que dans ce dossier (défaut : celui du schéma)
skemo render --batchplusieurs schémas dans un seul processus : une demande JSON par ligne en entrée, une réponse par ligne en sortie
skemo capabilities --format jsonversion, version des conventions SVG, fonctions

Des images qui se rouvrent

Comme draw.io, chaque fichier rendu par skemo porte sa source et ses feuilles de style (PNG, APNG, SVG, WebP, GIF et HTML), dans des métadonnées que les visionneuses ignorent. L’image peut se partager seule et se modifier plus tard :

skemo extract diagramme.png              # écrit diagramme.skemo et ses feuilles de style à côté de l’image
skemo render diagramme.png -o nouveau.svg # toute commande accepte aussi l’image à la place de la source

L’éditeur ouvre directement une telle image. Le texte intégré est lisible par quiconque reçoit le fichier : rendez avec --no-source quand la source ne doit pas voyager avec l’image.

Un site de vues liées

Un système trop grand pour un seul dessin se lit mieux en plusieurs vues : le contexte, puis les conteneurs d’une partie, puis les composants d’un conteneur. Liez une carte au schéma qui la détaille, puis faites un site du dossier :

card#api.app(href="api.skemo") API          # dans shop/containers.skemo
card#db.store(href="containers.skemo#db") DB  # retour au-dessus, centré sur l’élément

skemo site architecture/ -o public/ --css architecture/c4.css

Chaque .skemo devient une page au même endroit (shop/api.html). Un lien vers un schéma montre une loupe au lieu du glyphe de lien ; un clic zoome sur la carte et ouvre sa page. index.skemo est la page d’accueil (sans lui, l’accueil montre une vignette de chaque schéma) ; le fil d’Ariane suit le plus court chemin depuis lui. Un lien vers un schéma absent est un avertissement (site-missing-diagram) ; un schéma refusé refuse le site. --css donne un style à tous les schémas ; les pages suivent le thème clair ou sombre du lecteur, avec un bouton (--theme light n'en dessine qu'un) ; le bord du panneau latéral règle sa largeur ; --title nomme le site. Le champ de recherche en haut (/) trouve une carte dans tous les schémas, par son titre, sa catégorie, son tag, sa zone ou ses lignes, et ouvre sa page centrée sur elle. Les pages ne demandent ni serveur ni réseau.

Complétion du shell

skemo completions bash (ou zsh, fish, elvish, powershell) écrit un script de complétion ; la commande n’apparaît pas dans --help. Chargez-le au démarrage du shell :

eval "$(skemo completions bash)"      # ~/.bashrc
source <(skemo completions zsh)       # ~/.zshrc

Langue

L’aide, les diagnostics et les messages suivent la langue du système (LANG, LC_ALL… comme d’habitude ; anglais et français aujourd’hui). SKEMO_LANG=fr la remplace. Les libellés dessinés par le moteur (mois, siècles) la suivent aussi, sauf si le diagramme les fixe avec diagram(lang="fr").

Déterminisme

Polices et thème sont intégrés : le même fichier donne la même image sur toutes les machines, ce qui permet de versionner et de comparer les fichiers rendus. watch n’écoute que sur 127.0.0.1.
