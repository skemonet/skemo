Des diagrammes avec les agents IA

skemo est une bonne cible pour les agents de code : l’agent écrit une courte description de la structure, et la partie coûteuse (coordonnées, tracé, rendu) tourne sur votre processeur.

Pourquoi ça économise des tokens

Pour dessiner un diagramme directement, un modèle doit écrire chaque coordonnée, chaque tracé et chaque couleur de l’image. Mesuré sur les exemples de la galerie, le SVG d’un diagramme, écrit aussi sobrement qu’une main soigneuse le ferait, est environ 12 fois plus long, en tokens, que la source skemo dont il est rendu (comment c’est mesuré). Sur une tâche complète, où lire l’entrée et regarder les images domine, la première mesure a donné environ un tiers de tokens en moins. Chaque token produit est un passage du modèle sur un GPU : moins de tokens, c’est moins de temps, de coût et d’énergie. Les modifications coûtent encore moins : renommer ou ajouter une carte, c’est une seule ligne changée, là où une image dessinée doit être régénérée.

La compétence skemo

La compétence est un fichier SKILL.md qui apprend à un agent la démarche (écrire, vérifier, rendre), la syntaxe et les règles qui gardent les diagrammes courts et justes. Elle fonctionne avec Claude Code et avec tout agent qui charge des compétences dans ce format.

mkdir -p ~/.claude/skills/skemo/references
curl -fsSL https://skemo.net/skill/skemo/SKILL.md -o ~/.claude/skills/skemo/SKILL.md
curl -fsSL https://skemo.net/skill/skemo/references/format.md -o ~/.claude/skills/skemo/references/format.md

Pour un seul projet, placez plutôt le dossier dans .claude/skills/skemo/ à la racine du dépôt. L’agent a aussi besoin de l’exécutable skemo dans son PATH (installation).

Ce que fait l’agent

  1. Il écrit nom.skemo (et un petit nom.css pour ses types), sans coordonnées.
  2. Il lance skemo check nom.skemo et corrige les lignes signalées.
  3. Il rend avec skemo nom.skemo (PNG) ou -o nom.svg, et regarde l’image pour en juger.
  4. Les changements suivants sont des modifications de lignes dans le même fichier.

Conseils pour les demandes

  • Dites à quoi sert le diagramme et sa direction : « un diagramme skemo de gauche à droite de notre chaîne de déploiement ».
  • Demandez des types en CSS plutôt que des couleurs sur chaque carte.
  • Gardez le fichier .skemo dans le dépôt à côté de la documentation qu’il illustre, et refaites son rendu en CI avec skemo check --deny-warnings ou skemo render --deny-warnings.
