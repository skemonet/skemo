Documentation de skemo

skemo est un langage pour les diagrammes. Vous écrivez les cartes, les zones qui les regroupent et les flèches entre elles en quelques lignes de texte indenté ; skemo les place, trace les flèches et rend le résultat en PNG, SVG, WebP, HTML animé ou GIF.

Où l’utiliser

Diagrammes en codedans Git, relus en pull request, rendus en CI Agents IAune compétence qui apprend skemo aux agents de code

Pourquoi du texte

  • Le texte est la source. Un diagramme se lit, se relit avec git diff et se corrige comme du code.
  • Le placement est automatique. Aucune coordonnée à entretenir ; épinglez seulement ce qui doit rester fixe.
  • Les modifications restent locales. Changer une carte ne déplace que les flèches qui y sont attachées.
  • Le style, c’est du CSS. Un type de carte tient en une ligne : une couleur d’accent et une étiquette. Les thèmes clair, sombre et impression suivent.
  • Économe pour les agents IA. Un agent écrit quelques centaines de tokens de texte au lieu de milliers de coordonnées SVG.
