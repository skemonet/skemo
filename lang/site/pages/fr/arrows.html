Flèches

Une flèche s’écrit dans la carte qu’elle quitte : to(cible). Ses classes la stylent, son texte l’étiquette.

Écrire une flèche

card#api API
  to(db)                      //- api → db
  to(queue).dashed événements //- stylée, avec une étiquette
card#db Base de données
card#queue File

La cible est l’#id d’une carte. Une cible inconnue est une erreur, avec une suggestion quand l’id ressemble à un id existant. Les flèches peuvent revenir en arrière, former des cycles ou relier une carte à plusieurs autres.

Styles

ClasseEffet

.pulseun point lumineux qui court de la source à la pointe

Les classes se combinent (to(b).dashed.both). Vos propres classes colorent les flèches en CSS : .edge.important { color: #E8590C; }. Quand le sens ou la nature d’une flèche compte, donnez-lui aussi un style de trait, pas seulement une couleur, pour qu’elle se lise en noir et blanc.

Flèches en mouvement (préversion)

.flow et .pulse tournent en boucle tant que le diagramme est affiché. Tous les points vont à la même vitesse : ceux de toutes les flèches partent ensemble et une longue flèche prend plus de temps. Ils sont joués dans le HTML (arrêtés pour un lecteur qui demande moins d’animations), en GIF, APNG et WebP animé, et dans le SVG si vous le demandez avec --motion. Une image fixe les dessine en traits pleins. Voir Flux animés.

.edge.orders { --pulse-color: #E8590C; --pulse-size: 7px; --pulse-speed: 200px; }
.edge.flow   { --flow-speed: 30px; }   /* px par seconde */

Plusieurs cibles

to(w1 w2 w3) crée une flèche par cible, toutes avec les mêmes classes et la même étiquette (une étiquette est donc répétée sur chaque flèche).

Tronc commun

Avec join="trunk", les flèches d’un même to(…) partent du même point et partagent un tronc avant de se séparer, comme dans un organigramme. Chaque cible garde sa propre flèche, avec son id et son marqueur d’animation.

(Préversion) Des flèches simples d’une carte vers plusieurs cartes de la rangée suivante sont dessinées ainsi sans rien demander (une fourche). Quand plusieurs cartes relient chacune les mêmes cartes de la rangée suivante, toutes à toutes, leurs flèches partagent une barre entre les rangées (un bus) au lieu de se croiser. Les jonctions sont marquées d’un point.

(Préversion) Tout autre nom fait se rejoindre des flèches vers une carte : des flèches vers la même carte qui portent le même join="http", écrites sous des cartes différentes, se rejoignent avant elle et finissent sur une seule ligne avec une seule pointe (les appels HTTP de deux frontaux vers un même back-end, dans l’exemple Kubernetes de Placement). Un nom qu’aucune autre flèche vers cette carte ne porte est signalé et ignoré. Leur étiquette nomme tout le flux : elle se place sur la partie commune, juste avant la carte.

Une ligne sans pointe (.nohead, .link, une pointe en forme de point) va jusqu’à la carte.

Flèches hors du placement (préversion)

constraint="false" dessine et trace une flèche sans la laisser façonner le placement : sa cible n’est pas repoussée d’une rangée. Utilisez-le pour les liens transversaux (découverte de services, supervision, rappels) qui feraient sinon du diagramme une longue chaîne. Ici, CoreDNS reste à côté des pods au lieu de passer dessous.

Classes venues des extrémités

Chaque flèche reçoit automatiquement les classes from-<type> et to-<type> des cartes qu’elle relie : une seule règle CSS peut colorer toutes les flèches qui quittent ou rejoignent un type.

Côtés, points de passage, ids

AttributEffet
side="right-top"côté de départ et côté d’arrivée, parmi top bottom left right. Une moitié peut rester vide : side="-top"
via="x,y x,y"points de passage du tracé, dans l’ordre
href="…"la flèche est un lien (SVG et HTML)
to#id(…)un id explicite ; par défaut une flèche s’appelle source->cible (puis #2, #3 pour les doublons)

Voir Placement et positions pour savoir quand utiliser side et via.

Tracé

Chaque flèche est tracée à angles droits, autour des cartes et des zones qui ne contiennent aucune de ses extrémités. Les coudes se placent au milieu du couloir libre, et les flèches qui partagent un côté sont écartées. Vous ne dessinez jamais un tracé vous-même.
