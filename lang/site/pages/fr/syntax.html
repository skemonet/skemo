Syntaxe

Un fichier .skemo est un document Pug valide qui utilise une poignée de balises et des lignes écrites | texte. Chaque ligne est un élément ; l’indentation dit ce qui contient quoi ; le texte des lignes suit Markdown.

Balises et lignes

ÉcrireRôleContenu
diagram(…)première ligne facultative : options globalestout le reste, indenté dessous
card#id.typeune cartetexte = titre · | … = lignes de contenu · to(…) = flèches qui en partent
zone#id.typeun groupetexte = titre · | … = lignes de description · cartes et zones indentées
to(cible).typeune flèche, dans sa carte sourcetexte = étiquette (facultative)
| texteune ligne de la carte, de la zone ou du titre au-dessusemphase Markdown ; une ligne qui finit par | est une ligne de tableau

title, cards et stack complètent l’ensemble : voir Cartes et zones. Les classes collent au symbole qui ouvre : |.warn texte donne à une ligne la classe warn ; | .env (avec une espace d’abord) est le texte « .env ».

Anatomie d’une ligne

card#fw.t0.critical(tag="Edge" at="40,120") Pare-feu périmétrique   @2:up
│    │  │           │                       │                       └ marqueur d’animation (facultatif)
│    │  │           │                       └ texte : le titre
│    │  │           └ attributs : un seul groupe, entre parenthèses
│    │  └ classes : les types de la carte, stylés en CSS (plusieurs permis)
│    └ id : unique, sert de cible aux flèches
└ balise
  • Id : # suivi de lettres, chiffres, _ ou -. Toute carte ou zone visée par une flèche en a besoin, et les ids sont uniques dans le fichier.
  • Classes : .nom, autant que vous voulez. Ce sont des classes CSS : voir Styler en CSS.
  • Attributs : nom="valeur", séparés par des espaces ou des virgules. Un nom seul est une cible de flèche dans to(a b). Les valeurs prennent des guillemets doubles ou simples ; les nombres peuvent s’en passer.
  • Texte : tout ce qui suit la première espace après la balise.

Un seul groupe d’attributs par balise

Les attributs vont dans une seule paire de parenthèses, juste après l’id ou les classes :

to(core side="right-top").dashed      ✓
to(core).dashed(side="right-top")     ✗ erreur : plusieurs groupes d’attributs

Indentation

L’imbrication suit l’indentation. Utilisez 2 espaces (recommandé) ou des tabulations, mais jamais les deux dans un fichier. Une zone contient des cartes et des zones ; une carte ne contient que des lignes | et des flèches to(…).

Anciennes écritures

Les fichiers écrits avant la forme actuelle du langage s’ouvrent encore : li texte se lit | texte, from/to sur diagram se lisent start/end, step=/fx= se lisent comme des marqueurs @. skemo fmt les réécrit.

Mise en forme

skemo fmt fichier.skemo réécrit un fichier sous sa forme canonique (indentation, ordre des attributs, marqueurs) ; skemo fmt --check dit seulement s’il est déjà en forme. Les commentaires et l’ordre des éléments sont conservés.

Extension de fichier

.skemo. Le contenu reste du Pug valide : un éditeur peut utiliser sa coloration Pug.
