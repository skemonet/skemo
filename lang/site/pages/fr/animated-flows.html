Flux animés (préversion)

Deux classes de flèche tournent en boucle tant que le diagramme est affiché : .pulse envoie un point lumineux de la source à la pointe, .flow fait défiler des tirets sur la ligne. On voit d’un coup d’œil où vont les requêtes et les événements.

Le diagramme ci-dessus bouge dans votre navigateur : c’est la sortie SVG avec --motion.

Comment l’écrire

  • to(gateway).pulse requêtes : un seul point par flèche à la fois. Tous les points vont à la même vitesse : ceux de toutes les flèches partent ensemble, et une flèche longue prend plus de temps.
  • to(kafka).flow événements : des tirets qui avancent vers la pointe, pour un flux continu.
  • Les réglages sont des propriétés CSS sur la classe de la flèche :
.edge.orders { --pulse-color: #E8590C; --pulse-size: 7px; --pulse-speed: 200px; }
.edge.flow   { --flow-speed: 30px; }   /* px par seconde */

Où ça bouge

SortieMouvement
HTML (-o f.html)joué ; arrêté pour les lecteurs qui demandent moins d’animations à leur système
SVG avec --motionjoué, y compris dans une balise <img> (animation CSS, sans script)
GIF, APNG, WebP animéune boucle, image par image ; l’APNG rend le mieux les couleurs du halo
PNG, WebP, SVG sans --motionfixe : les flèches sont dessinées en traits pleins

Mouvement et étapes se combinent : un diagramme qui se déploie pas à pas peut avoir des flèches animées à chaque étape (Animations pas à pas).
