Styler en CSS

Les classes sont des types, les types se stylent en CSS. Un type n’a besoin que d’une couleur d’accent et d’une étiquette ; toutes les teintes en découlent.

Rendez avec la feuille de style : skemo types.skemo --css types.css. --css peut se répéter ; les fichiers s’appliquent après le thème par défaut, avec la cascade habituelle.

Un type en une ligne

.server { --c: #5B6CFF; --label: "SERVEUR"; }

--c est l’accent : la bande, la bordure et le fond teinté de la carte en viennent tous, par color-mix() avec les couleurs de surface du thème. --label est le texte du badge ou de la pastille (omettez-le pour ne pas avoir de badge ; tag="…" sur une carte le remplace). Comme rien d’autre n’est figé, le même type fonctionne dans les thèmes clair, sombre et impression.

Ne définissez ni background ni couleurs de texte sur les types. Utilisez les variables (var(--surface), var(--ink)…) s’il le faut, sinon les thèmes sombre et impression casseront.

skemo theme --print affiche tout le thème par défaut : un bon point de départ pour votre propre thème, que --base-theme utilise alors à la place de celui par défaut.

Flèches

La couleur d’une flèche est sa color ; les pointes la suivent. Les traits sont des chemins SVG :

.edge.ok { color: #2B8A3E; }
.edge.ko .line { stroke-dasharray: 5 4; }
.edge.from-uplink { color: #7B5CC4; }    /* toutes les flèches qui quittent une carte .uplink */

Apparences des cartes

Quatre apparences, pour tout le diagramme avec diagram(look="…") ou par type avec --look :

band (par défaut) : le nom dans une bande colorée, la pastille à droite

header : le type dans la bande, le nom centré dessous

classic : un filet d’accent en haut, un badge avant le nom

eyebrow (préversion) : une carte blanche, le type en petite étiquette colorée au-dessus du nom

Dans toutes les apparences, une carte sans type est dessinée claire : blanche, avec une bordure fine. La couleur est laissée aux types qui ont un sens.

Viser un seul élément

Dans les sorties SVG et HTML, les ids sont écrits en data-id, pour que plusieurs diagrammes partagent une page. Visez une carte avec un sélecteur d’attribut :

[data-id="fw"] { --c: #C94A44; }

Autres sélecteurs sur lesquels compter : card, zone, card > .title, card li (un par ligne |), card table, card mark, .edge, .edge .line, .edge .head, .edge .edge-label. L’étiquette d’une flèche est dans sa flèche et prend sa couleur : .edge.ok { color: #2B8A3E; } teinte à la fois le trait et la pastille de l’étiquette (préversion). Ces noms appartiennent au dessin : ne les prenez pas comme noms de types.

Polices (préversion)

skemo embarque Inter et JetBrains Mono et ne lit aucune police du système : un diagramme se mesure et se rend pareil partout. Pour utiliser une autre police, nommez sa famille dans le CSS et donnez ses fichiers au moteur, un par graisse ou style :

.stage { --font: 'Source Serif 4', serif; }
skemo render plan.skemo --css plan.css --font SourceSerif4-Regular.ttf --font SourceSerif4-Bold.ttf

La famille, la graisse et le style sont lus dans chaque fichier (TrueType ou OpenType). La police sert à la mesure et à toutes les sorties ; le HTML l’embarque, le SVG aussi avec --embed-fonts. Une famille qu’aucune police ne dessine retombe sur Inter, avec un avertissement qui la nomme. N’utilisez que des polices dont la licence permet l’intégration.
