skemo documentation

skemo is a language for diagrams. You write cards, the zones that group them and the arrows between them as a few lines of indented text; skemo lays them out, routes the arrows and renders the result as PNG, SVG, WebP, animated HTML or GIF.

Why text

  • The text is the source. A diagram is read, reviewed with git diff and fixed like code.
  • Layout is automatic. No coordinates to maintain; pin only what you want fixed.
  • Edits stay local. Changing one card only moves the arrows attached to it.
  • Style is CSS. A card type is one line: an accent colour and a label. Light, dark and print themes follow.
  • Cheap for AI agents. An agent writes a few hundred tokens of text instead of thousands of SVG coordinates.
