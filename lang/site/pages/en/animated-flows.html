Animated flows (preview)

Two arrow classes loop for as long as the diagram is shown: .pulse sends one glowing dot from the source to the head, .flow streams dashes along the line. They show where requests and events go, at a glance.

The diagram above moves in your browser; it is the SVG output with --motion.

How it is written

  • to(gateway).pulse requests: one dot per arrow at any time. Every dot runs at the same speed, so the dots of all arrows leave together and a long arrow takes longer.
  • to(kafka).flow events: dashes moving towards the head, for a continuous stream.
  • Settings are CSS properties on the arrow's class:
.edge.orders { --pulse-color: #E8590C; --pulse-size: 7px; --pulse-speed: 200px; }
.edge.flow   { --flow-speed: 30px; }   /* px per second */

Where it plays

OutputMotion
HTML (-o f.html)plays; stopped for readers who ask their system for less motion
SVG with --motionplays, also inside an <img> tag (CSS animation, no script)
GIF, APNG, animated WebPone loop, frame by frame; APNG keeps the glow's colours best
PNG, WebP, SVG without --motionstill: the arrows are drawn as plain solid lines

Motion and steps combine: a diagram that unfolds step by step can have pulsing arrows at every step (Step-by-step animations).
