Command line

skemo is a single executable. Rendering is its default command: skemo f.skemo writes f.png.

Commands

CommandRole
skemo f.skemosame as skemo render f.skemo: writes f.png next to the source
skemo render f.skemo -o out.extthe extension picks the format: png svg webp html gif apng
skemo check f.skemo…diagnostics only (exit code 1 on errors); --contrast adds the legibility check
skemo fmt f.skemo… [--check]canonical formatting
skemo watch f.skemolive preview on http://127.0.0.1:8710, reloaded on every save
skemo layout f.skemo --jsonmodel, positions and routes as JSON
skemo fit f.skemo [--target 16:9] [--write]settings (dir, wrap) that bring the diagram to a target aspect ratio; --write applies the best one (preview)
skemo extract image.png [-o folder]gives back the source and stylesheets embedded in an image rendered by skemo, to edit them (--stdout: the source only)
skemo icons [query]the built-in icons, filtered by name or tag
skemo theme --printthe default theme, a starting point for your own
skemo init [folder]a sample diagram and a commented CSS file; overwrites nothing

Render options

OptionEffect
-o FILEoutput file; - = standard output (with --format)
--format FMThtml svg png gif apng webp, when the extension is not enough
--css FILEcustom stylesheet, after the theme (repeatable)
--base-theme FILEa theme that replaces the default one
--theme Tlight dark print auto, overriding the file
--scale Nresolution of raster outputs (--scale 2 for high-density screens)
--transparentno background (SVG, PNG, APNG)
--contrast hightexts below the WCAG threshold are darkened or lightened, layout unchanged
--step Nrender one animation state
--animated, --boardone PNG per state, or a contact sheet of the states
--hold, --transition, --fps, --final-hold, --no-loop timing of GIF and APNG
--no-fontsHTML: do not embed the fonts (much smaller file)
--embed-fontsSVG: embed the fonts used, for viewers without Inter (about 0.8 MB per weight)
--font-scale Kmultiply every text size of the theme (1.4 for a slide)
--no-sourcedo not embed the source and stylesheets in the output (below)
--deny-warningsfail on any warning (useful in CI)

The input - reads standard input: cat f.skemo | skemo render - --format svg -o - > f.svg.

Images that reopen

Like draw.io, every file skemo renders carries its source and its stylesheets (PNG, APNG, SVG, WebP, GIF and HTML), in metadata that viewers ignore. The image can be shared alone and edited later:

skemo extract diagram.png          # writes diagram.skemo and its stylesheets next to the image
skemo render diagram.png -o new.svg # any command also takes the image instead of the source

The editor opens such an image directly. The embedded text is readable by anyone who gets the file: render with --no-source when the source must not travel with the image.

Exit codes

0success
1errors in the file
2wrong usage
3internal error

Language

Help, diagnostics and messages follow the system language (LANG, LC_ALL… as usual; English and French today). --lang en|fr or SKEMO_LANG=fr overrides it. Labels the engine draws (months, centuries) follow it too, unless the diagram pins them with diagram(lang="en").

Determinism

Fonts and theme are embedded: the same file gives the same image on every machine, which makes rendered files safe to commit and compare. watch only listens on 127.0.0.1.
